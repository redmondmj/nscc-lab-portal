Dynamic Ansible Inventory

You can query or pass this portal directly as a dynamic inventory source to Ansible. Groups are structured by course and published lab templates.

Inventory URL: http://10.10.0.103/api/admin/ansible/inventory
Preview JSON Inventory →

Usage with Ansible Playbooks:

# Run a playbook targeting all OSYS1200 student VMs:
ansible-playbook -i "http://10.10.0.103/api/admin/ansible/inventory" playbooks/audit_lab.yml --limit osys1200

# Ping all active VMs in the fleet:
ansible -i "http://10.10.0.103/api/admin/ansible/inventory" all -m win_ping
